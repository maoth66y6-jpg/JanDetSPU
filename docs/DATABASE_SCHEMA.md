# โครงสร้างฐานข้อมูล (Database Schema) - จานเด็ด SPU 🗄️

เอกสารนี้ระบุรายละเอียดโครงสร้างของข้อมูลและ Data Models ที่จัดเก็บใน LocalStorage (`localStorage`) และไฟล์ฐานข้อมูลเซิร์ฟเวอร์ (`server/data/*.json`)

---

## 1. ข้อมูลผู้ใช้งานและผู้สมัคร (`users`)

| ฟิลด์ (Field) | ชนิดข้อมูล (Type) | คำอธิบาย (Description) |
|---|---|---|
| `id` | String | รหัสเฉพาะของผู้ใช้ เช่น `usr_admin` หรือ `usr_1731254000` |
| `name` | String | ชื่อ-นามสกุล หรือชื่อเล่นในมอ |
| `studentId` | String | รหัสนักศึกษา เช่น `65012345` หรือรหัสสมาชิก |
| `faculty` | String | คณะ / สำนักวิชา เช่น "คณะเทคโนโลยีสารสนเทศ" |
| `phone` | String | เบอร์โทรศัพท์ติดต่อ |
| `email` | String | อีเมล เช่น `name@spu.ac.th` |
| `password` | String | รหัสผ่านผู้ใช้งาน |
| `role` | String | สิทธิ์ในระบบ (`admin` หรือ `student`) |
| `userType` | String | ประเภท (`นักศึกษา`, `อาจารย์/เจ้าหน้าที่`, `บุคคลทั่วไป`) |
| `status` | String | สถานะการสมัคร (`อนุมัติแล้ว`, `รอตรวจสอบ`) |
| `avatar` | String (URL) | ลิงก์รูปถ่ายประจำตัวผู้ใช้ |
| `checkInStreak`| Number | จำนวนวันสตรีคที่ล็อกอินสะสมในรอบสัปดาห์ (1 - 7 วัน) |
| `lastCheckInDate` | String (YYYY-MM-DD) | วันที่ล็อกอินเช็กอินล่าสุด ป้องกันการทำซ้ำ |
| `unlockedFrames` | Array<String> | รายการรหัสกรอบรูปโปรไฟล์ที่ปลดล็อกแล้ว |
| `equippedFrame` | String | รหัสกรอบรูปโปรไฟล์ที่กำลังสวมใส่อยู่ |
| `customTitle` | String | ฉายานักชิมที่กำลังใช้งาน |
| `badges` | Array<String> | รายการบัดจ์เกียรติยศที่ได้รับ |
| `favorites` | Array<String> | รายการรหัสร้านอาหารโปรดที่บันทึกไว้ |
| `createdAt` | String | วันที่สมัครสมาชิก |

---

## 2. ข้อมูลร้านอาหาร (`restaurants`)

| ฟิลด์ (Field) | ชนิดข้อมูล (Type) | คำอธิบาย (Description) |
|---|---|---|
| `id` | String | รหัสเฉพาะของร้านอาหาร เช่น `rst_1731254000` |
| `name` | String | ชื่อร้านอาหาร |
| `location` | String | พิกัดโรงอาหาร เช่น "โรงเย็น อาคาร 10 (ชั้น 1)" หรือ "โรงร้อน (หลังอาคาร 5)" |
| `category` | String | หมวดหมู่อาหาร (ตามสั่ง, ก๋วยเตี๋ยว, สเต็ก, เครื่องดื่ม ฯลฯ) |
| `priceRange` | String | ช่วงราคา เช่น "40 - 60 บาท" |
| `avgPrice` | Number | ราคาเฉลี่ยของเมนูในร้าน |
| `rating` | Number | คะแนนเฉลี่ยตั้งต้น |
| `image` | String (URL) | รูปภาพหน้าร้านหรืออาหารเด่น |
| `description` | String | คำอธิบายและจุดเด่นของร้าน |
| `openHours` | String | เวลาเปิด-ปิด เช่น "08:00 - 17:00 น." |
| `tags` | Array<String> | คำค้นหาด่วน เช่น `["กะเพรา", "เนื้อเปื่อย", "ยอดนิยม"]` |
| `menus` | Array<Object> | รายการเมนูอาหารของร้าน (ชื่อ, ราคา, เมนูแนะนำ) |

---

## 3. ข้อมูลสถิติการเข้าชมเว็บ (`analytics`)

| ฟิลด์ (Field) | ชนิดข้อมูล (Type) | คำอธิบาย (Description) |
|---|---|---|
| `pageViews` | Number | จำนวนครั้งการเปิดชมหน้าเว็บทั้งหมด |
| `uniqueVisitors` | Number | จำนวนผู้เข้าชมที่ไม่ซ้ำคน (นับจาก Visitor UUID) |
| `dailyVisits` | Object (Map) | สถิติการเข้าชมแยกตามวัน เช่น `{"2026-11-10": 142}` |
| `lastHit` | String (ISO Date) | เวลาที่มีการเข้าชมล่าสุด |
