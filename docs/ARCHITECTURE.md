# สถาปัตยกรรมระบบ (System Architecture) - จานเด็ด SPU 🍛✨

เอกสารนี้อธิบายโครงสร้างและการออกแบบเชิงสถาปัตยกรรมของโครงการ **จานเด็ด SPU** ซึ่งเป็นแอปพลิเคชัน Full-Stack ที่รองรับทั้งการทำงานแบบ **Standalone (Client-Side Only via `file:///`)** และ **Localhost Server (Client-Server Architecture via `http://localhost:3000`)**

## 🔑 คุณสมบัติเด่นของการออกแบบ (Key Design Principles)

### 1. Dual-Mode Execution (ทำงานได้ 2 โหมดในโค้ดเดียว)
- **โหมดที่ 1: Standalone (Zero Configuration)**
  - ผู้ใช้งานหรืออาจารย์สามารถดับเบิลคลิกไฟล์ `index.html` เพื่อเข้าใช้งานได้ทันที 100%
  - ข้อมูลทั้งหมดจะถูกจัดการและบันทึกลงใน `localStorage` ของเบราว์เซอร์
- **โหมดที่ 2: Localhost Server (Full-Stack Mode)**
  - รันผ่าน Node.js เซิร์ฟเวอร์ที่พอร์ต `3000` โดยรันคำสั่ง `node server.js` หรือดับเบิลคลิก `start-server.bat`
  - มี REST API คอยรับส่งข้อมูลสถิติคนเข้าชม, ร้านอาหาร, รีวิว และข้อมูลผู้สมัคร

### 2. Zero External Assets for Sound (Web Audio API Synthesizer)
- ระบบเสียงของวงล้อและปุ่มกดใช้การสร้างคลื่นเสียงแบบเรียลไทม์ (OscillatorNode & GainNode) ทำให้ไม่ต้องพึ่งพาไฟล์เสียง `.mp3` ภายนอก หมดปัญหาเรื่องไฟล์เสียงหายหรือติด CORS

### 3. State Isolation & Security
- หน้าต่างตั้งค่า Google Client ID และปุ่มคืนค่าข้อมูลเริ่มต้น (Reset) ถูกจำกัดสิทธิ์เฉพาะผู้ดูแลระบบ (Admin)
- บุคคลทั่วไปที่เข้าชมเว็บไซต์จะไม่สามารถเห็นเครื่องมือตั้งค่าหรือฟังก์ชันแอดมินใดๆ
