# จานเด็ด SPU (SPU Best Dishes & Canteen Review System) 🍛✨
> เว็บไซต์รีวิวอาหาร ค้นหาร้านเด็ด วงล้อสุ่มเมนู และระบบบริหารจัดการโรงอาหารมหาวิทยาลัยศรีปทุม (Full-Stack Standalone & Localhost Application)

---

## 🎯 วัตถุประสงค์โครงการ
โครงการ **"จานเด็ด SPU"** ถูกพัฒนาขึ้นเพื่อแก้ปัญหาประจำวันของนักศึกษา คณาจารย์ และบุคลากรมหาวิทยาลัยศรีปทุม:
1. **แก้ปัญหา "เที่ยงนี้กินอะไรดี?":** มินิเกม **วงล้อเสี่ยงทายจานเด็ด (Food Roulette)** ช่วยสุ่มเลือกร้านและเมนูอาหารในมอได้อย่างสนุกสนาน
2. **ศูนย์รวมรีวิวร้านอาหารในโรงอาหาร SPU:** รองรับพิกัดโรงอาหารจริง ได้แก่ **โรงเย็น อาคาร 10 (ชั้น 1, ชั้น 2, ชั้น 3)** และ **โรงร้อน (หลังอาคาร 5)**
3. **ระบบล็อกอินด้วย Google Cloud Console & สมาชิก:** เข้าสู่ระบบด้วย Google OAuth 2.0 Web Client ID หรือสมัครสมาชิกด้วยอีเมล พร้อมรูปถ่ายโปรไฟล์ส่วนตัว
4. **ระบบนับผู้เข้าชมเว็บ (Visitor Analytics Counter):** นับจำนวนการเข้าชมหน้าเว็บทั้งหมด (Page Views) และจำนวนผู้เข้าชมไม่ซ้ำ (Unique Visitors) แบบเรียลไทม์
5. **ระบบจัดการข้อมูลผู้สมัคร (Applicant Dossier Management):** เก็บข้อมูลรหัสนักศึกษา, คณะ/สังกัด, เบอร์โทรศัพท์ และดูใบสมัครอย่างละเอียด
6. **ระบบล็อกอินรายสัปดาห์ (Weekly 7-Day Streak):** สะสมสตรีคต่อเนื่อง 7 วันเพื่อรับรางวัลใหญ่ประจำสัปดาห์ (กรอบ Cyberpunk Pink-Black และฉายาสุดยอดนักชิม 7 วัน SPU)
7. **ระบบผู้ดูแลระบบ (Secret Admin Access):** แอดมินสามารถประหารคอมเมนต์ (ลบรีวิวที่ไม่เหมาะสม), จัดการเพิ่ม/แก้ไข/ลบร้านอาหาร, เปลี่ยนธีมเทศกาล, และตั้งค่า Google Client ID

## 🚀 วิธีการเปิดใช้งานระบบ (2 โหมดการใช้งาน)

### โหมดที่ 1: รันผ่าน Localhost (Node.js Full-Stack Mode) 🌐
เหมาะสำหรับการนำเสนอผลงาน การพัฒนา หรือทดสอบระบบหลังบ้าน REST API:
1. **ดับเบิลคลิกที่ไฟล์ `start-server.bat`** (บน Windows) หรือเปิด Terminal แล้วรัน:
   ```bash
   node server.js
   ```
2. ระบบจะเริ่มทำงานที่พอร์ต `3000` และเปิดหน้าเว็บให้ทันทีที่:
   ```text
   http://localhost:3000
   ```
3. พร้อมบริการ REST APIs ที่เส้นทาง `http://localhost:3000/api/*`

### โหมดที่ 2: รันแบบ Standalone (Zero Configuration) 💻
ไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ใดๆ:
- เพียง **ดับเบิลคลิกเปิดไฟล์ `index.html`** ในเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox)
- ระบบสามารถทำงานได้สมบูรณ์ 100% ทันทีผ่าน `file:///` protocol

## ✨ ฟีเจอร์หลักและการปรับปรุงล่าสุด

### 1. 🛡️ การแยกมุมมองผู้ดูแลระบบ (Admin) ออกจากผู้ใช้งานทั่วไปอย่างชัดเจน
- **Google Client ID Configuration:** ย้ายการแสดงสถานะและการตั้งค่า Client ID ไปไว้ใน **แผงควบคุมผู้ดูแลระบบ (Admin Control Panel)** เท่านั้น ในหน้าต่างล็อกอินของคนทั่วไปจะแสดงเฉพาะปุ่ม Google Sign-In ที่สะอาดตา
- **ปุ่มคืนค่าข้อมูลเริ่มต้น (Reset Demo Data):** ซ่อนจากผู้เข้าชมทั่วไป และจะแสดงผลเฉพาะเมื่อผู้ดูแลระบบ (Admin) เข้าสู่ระบบเท่านั้น
- **กล่องสถานะเมื่อยังไม่มีร้านอาหารในระบบ (Empty State):**
  - **สำหรับบุคคลทั่วไป/นักศึกษา:** แสดงข้อความสุภาพและเป็นกันเองว่า:  
    `🍽️ ตอนนี้ยังไม่มีร้านแนะนำลองมาใหม่ในรอบหน้านะครับ` (ผู้ดูแลระบบกำลังเตรียมข้อมูลร้านอาหารอร่อยๆ ในโรงอาหาร SPU ไว้ให้คุณ)
  - **สำหรับผู้ดูแลระบบ (Admin):** แสดงกล่องแอดมินพร้อมปุ่ม `➕ เพิ่มร้านอาหารแรกของคุณเลย!` เพื่อให้แอดมินใส่ข้อมูลร้านอาหารได้ทันที

### 2. 📊 ระบบหลังบ้านนับจำนวนคนเข้าชมเว็บ (Visitor Analytics)
- นับจำนวนการเข้าชมหน้าเว็บทั้งหมด (**Page Views**)
- นับจำนวนผู้เข้าชมไม่ซ้ำ (**Unique Visitors**)
- สถิติการเข้าชมรายวัน (**Daily Breakdown**)
- แสดงผลในแผงควบคุมสถิติแอดมิน และแถบ Badge แสดงยอดเข้าชมที่ส่วนท้ายเว็บไซต์ (Footer)

### 3. 👥 ระบบข้อมูลผู้สมัครสมาชิก (Applicant Dossier & Faculty Filter)
- รองรับการกรอกข้อมูลผู้สมัคร:
  - 🆔 **รหัสนักศึกษา / รหัสสมาชิก**
  - 🏛️ **คณะ / สำนักวิชา** (เช่น คณะเทคโนโลยีสารสนเทศ, คณะบริหารธุรกิจ, คณะนิเทศศาสตร์ ฯลฯ)
  - 📞 **เบอร์โทรศัพท์ติดต่อ**
  - 🎓 **ประเภทผู้ใช้** (นักศึกษา, อาจารย์/บุคลากร, บุคคลทั่วไป)
- ในแผงแอดมินมี **ตัวกรองค้นหาตามคณะ** และปุ่ม **"👁️ ใบสมัคร"** เพื่อเปิดดูแฟ้มประวัติผู้สมัครและสถิติการใช้งานอย่างละเอียด

### 4. 📅 ระบบล็อกอินสะสมรายสัปดาห์ & ปฏิทินของรางวัล 2 เดือน (8-Week Streak Roadmap)
- **🔥 เลขไฟสตรีคเพิ่มขึ้นเรื่อยๆ (Continuous Fire Streak):** เลขไฟสะสมความต่อเนื่องจะไม่ถูกตัดกลับเป็น 1 เมื่อครบ 7 วัน แต่จะนับเพิ่มขึ้นอย่างต่อเนื่อง (1, 2, ... 7, 8, ... 14, ... 28, ... 56, 60+ วัน) แสดงบน Header, ตารางอันดับ (Leaderboard), แถบโปรไฟล์ และข้อมูลส่วนตัว
- **⚪ กรอบพื้นฐานสำหรับสมาชิกใหม่ (Base Frame):** ผู้ใช้งานที่เพิ่งสมัครเข้ามาจะเริ่มต้นด้วยกรอบพื้นฐาน (`frame-none`) มินิมอลเรียบหรู และสามารถสะสมสตรีคเพื่อปลดล็อกกรอบสีสะท้อนแสงทั้ง 8 สัปดาห์
- **👑 รางวัลใหญ่ประจำวันที่ 7 ต่อเนื่องตลอด 2 เดือนเต็ม (8 สัปดาห์ไม่ซ้ำกัน):**
  1. **สัปดาห์ที่ 1 (ครบ 7 วัน):** กรอบ Cyberpunk Pink-Black ⚡ + ฉายา *"สุดยอดนักชิม 7 วัน SPU"*
  2. **สัปดาห์ที่ 2 (ครบ 14 วัน):** กรอบ Crystal Blue Canteen ❄️ + ฉายา *"จอมยุทธ์โรงเย็น อาคาร 10"*
  3. **สัปดาห์ที่ 3 (ครบ 21 วัน):** กรอบ Volcano Fire Canteen 🔥 + ฉายา *"ราชันย์กระทะร้อนหลังอาคาร 5"*
  4. **สัปดาห์ที่ 4 (ครบ 28 วัน / 1 เดือน):** กรอบ Emerald SPU Legend 💎 + ฉายา *"เซียนจานเด็ดศรีปทุม 1 เดือน"*
  5. **สัปดาห์ที่ 5 (ครบ 35 วัน):** กรอบ Cosmic Galaxy Violet 🌌 + ฉายา *"นักชิมทะลุมิติจักรวาล SPU"*
  6. **สัปดาห์ที่ 6 (ครบ 42 วัน):** กรอบ Sweet Pastel Rainbow 🌈 + ฉายา *"กูรูคาเฟ่ & ของหวานตัวแม่ SPU"*
  7. **สัปดาห์ที่ 7 (ครบ 49 วัน):** กรอบ Platinum Diamond Knight ⚔️ + ฉายา *"อัศวินนักล่าจานเด็ดระดับพรีเมียม"*
  8. **สัปดาห์ที่ 8 (ครบ 56 วัน / 2 เดือน):** กรอบ Grand Golden Emperor 👑 + ฉายา *"มหาเทพจานเด็ด SPU 60 วัน"*
- **🗺️ ผัง Roadmap 8 สัปดาห์:** แสดงบัตรของรางวัลตลอด 2 เดือนพร้อมสถานะปลดล็อกแบบเรียลไทม์
- **👀 ระบบนับผู้เข้าชมจริง (Production-Ready Visitor Counter):**
  - **Localhost Backend Mode:** ซิงค์ผ่าน Node.js REST API (`/api/visitors/hit` และ `/api/visitors/stats`) บันทึกลง `server/data/analytics.json` แยกตาม IP, Unique Visitor UUID, Page Views และประวัติการเข้าชม
  - **Live Web Deployment Mode (GitHub Pages / Vercel / Netlify / Cloud Host):** ซิงค์อัตโนมัติผ่าน Cloud Counter API ระดับสากล เพื่อให้นับจำนวนผู้เข้าชมจริงข้ามอุปกรณ์ ข้ามเครื่อง และข้ามเบราว์เซอร์ได้ 100%!
  - **Offline / Standalone Fallback:** รองรับการบันทึกระดับ LocalStorage ในกรณีที่ไม่มีการเชื่อมต่อเครือข่าย

### 5. 👨‍🍳 โลโก้มาสคอตประจำเว็บไซต์ (SPU Chef Mascot Logo)
- **อัตลักษณ์ประจำเว็บ:** นำภาพมาสคอตนักศึกษาเชฟหนุ่ม SPU สวมผ้าคาดศีรษะ *"จานเด็ด เอสพียู"* พร้อมกระทะกระทะไฟลุกมาจัดวางเป็นโลโก้หลักของเว็บไซต์
- **ขนาดพอดิบพอดี (Medium Proportion):** กำหนดขนาดความสูง 48px บนแถบ Navbar และ 52px บนแถบ Footer พอดีสายตา ไม่ใหญ่หรือเล็กจนเกินไป พร้อมเอฟเฟกต์หมุนเอียงเล็กน้อยอย่างน่ารักเมื่อเลื่อนเมาส์ชี้ (Hover)
- **ไอคอนเบราว์เซอร์ (Favicon):** บันทึกเป็นไอคอนแท็บเบราว์เซอร์คุณภาพสูงที่ `assets/icons/logo.png`

### 6. 📁 ระบบเพิ่มร้านอาหารของแอดมิน: อัปโหลดรูปภาพตรงจากคอมพิวเตอร์
- **Local File Upload:** แอดมินสามารถคลิกปุ่ม **"📁 เลือกไฟล์รูปภาพจากเครื่องคอมพิวเตอร์..."** เพื่อเลือกไฟล์ภาพจากฮาร์ดดิสก์ของเครื่องได้โดยตรง (รองรับ PNG, JPG, JPEG, WebP, GIF)
- **Dual Option Flexibility:** รองรับทั้งการอัปโหลดไฟล์จากเครื่อง (แปลงเป็น Base64 Data URL ผ่าน FileReader API) หรือจะใส่เป็น Image URL ตามปกติก็ได้
- **Instant Preview & Reset:** มีกล่องแสดงตัวอย่างรูปภาพทันทีพร้อมปุ่ม **"🔄 เปลี่ยนรูป"** และ **"❌ ลบรูปภาพ"** เพื่อความสะดวกในการตรวจสอบก่อนกดบันทึก

### 7. 👑 อภิสิทธิ์ผู้ดูแลระบบ (Admin Full Reward Privileges)
- ผู้ใช้งานที่มียศเป็นผู้ดูแลระบบ (`role === 'admin'`) จะได้รับ **สิทธิ์ในการเข้าถึงและสวมใส่ของรางวัลทั้งหมดในระบบได้ทันที**:
  - สวมใส่ **กรอบรูปโปรไฟล์ได้ทุกกรอบ** ทั้ง 8 สัปดาห์ (รวมถึง Grand Emperor, Cyberpunk, Volcano Fire ฯลฯ) และกรอบรีวิว โดยไม่ต้องรอสะสมสตรีคหรือทำเควสต์
  - เลือกสวมใส่ **ฉายาพิเศษ (Custom Titles) ได้ทุกฉายา** ในระบบ
  - ปลดล็อก **บัดจ์เกียรติยศ (Badges) ครบทุกเหรียญ**

## 🧪 การรันชุดทดสอบ (Automated Testing)
สามารถทดสอบการทำงานของระบบได้ผ่านคำสั่ง:
```bash
# รันการทดสอบ Backend และ REST APIs
node tests/backend.test.js

# รันการทดสอบ Frontend และความสมบูรณ์ของโมดอล
node tests/frontend.test.js

# หรือรันผ่านคำสั่ง npm
npm test
```

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend:** HTML5, CSS3 (Modern Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+), HTML5 Canvas
- **Backend:** Node.js HTTP Server, RESTful API Architecture
- **Authentication:** Google Identity Services (GIS) OAuth 2.0 Web Client ID
- **Sound Engine:** Web Audio API Realtime Synthesizer (Zero MP3 Dependencies)
- **Storage:** LocalStorage API (Standalone Mode) & JSON Database (Localhost Server Mode)
- **Version Control & Docs:** Git, Markdown, JSON Schema
