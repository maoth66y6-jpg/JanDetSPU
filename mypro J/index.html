💡 สิทธิอำนาจของผู้ดูแลระบบ (Admin Rights)

  • จัดการร้านอาหาร: เพิ่มร้านอาหารใหม่ แก้ไขข้อมูล ปรับราคา และเพิ่มเมนูอาหารในโรงเย็น อาคาร 10 และโรงร้อนหลังอาคาร 5
  • ประหารคอมเมนต์: สามารถลบรีวิวที่ไม่เหมาะสม หรือตอบรับรายงานจากผู้ใช้งานได้ทันที
  • เปลี่ยนธีมเทศกาล: เปลี่ยนบรรยากาศเว็บเป็น ลอยกระทง, ฮาโลวีน, คริสต์มาส, สงกรานต์, ตรุษจีน หรือ SPU Classic
  • จัดการข้อความ: แก้ไขข้อความแบนเนอร์ แถบประกาศ และสโลแกนหน้าเว็บได้ตลอดเวลา

👥 จัดการข้อมูลสมาชิกทั้งหมดในระบบ

ตรวจสอบ แก้ไขสิทธิ์ (Role) มอบฉายา หรือลบบัญชีผู้ใช้ที่สมัครเข้ามา

รูป รหัส & ชื่อผู้สมัคร คณะ / สังกัด อีเมล / เบอร์โทร ประเภท บทบาท สตรีค วันที่สมัคร การจัดการ

รายการร้านอาหารทั้งหมดในระบบ

รูป ชื่อร้าน พิกัดใน SPU หมวดหมู่ คะแนนเฉลี่ย จำนวนเมนู การจัดการ

🛡️ ศูนย์ประหารคอมเมนต์ & รีวิวที่ไม่เหมาะสม

ตรวจสอบรีวิวที่ถูกรายงานจากนักศึกษา หรือเลือกประหาร (ลบ) ได้ทันที

จัดการข่าวสารและโปรโมชั่น

🎨 เปลี่ยนธีมเทศกาลของเว็บไซต์ (Festival Theme)

เลือกธีมเทศกาลเพื่อเปลี่ยนโทนสี บรรยากาศ และเอฟเฟกต์อนุภาคที่ลอยในหน้าเว็บได้ทันที

✍️ แก้ไขข้อความในเว็บไซต์

⚙️ จัดการระบบ & Google Cloud Console

กำหนดค่าการเชื่อมต่อ Google Cloud OAuth 2.0 และจัดการข้อมูลของเว็บไซต์

ตั้งค่า Google Cloud Console OAuth 2.0 Web Client ID

นำ Client ID ที่ได้จาก Google Cloud Console (APIs & Services > Credentials > OAuth Client IDs) มาวางที่นี่เพื่อเปิดใช้งานการล็อกอิน Google จริง

⚠️ Google Client ID: ยังไม่ได้ตั้งค่า
สร้างได้ฟรีจาก Google Cloud Console

⚠️ คืนค่าข้อมูลเริ่มต้น (Reset Data)

การกดปุ่มนี้จะรีเซ็ตข้อมูลทั้งหมดกลับสู่ค่าเริ่มต้น (เฉพาะผู้ดูแลระบบเท่านั้นที่มีสิทธิ์ดำเนินการ)

Google Cloud Console OAuth 2.0

กำหนดค่า Google OAuth 2.0 Web Client ID จาก Google Cloud เพื่อให้ผู้ใช้งานสามารถกดล็อกอินด้วยบัญชี Google จริงได้ทันที:

📌 ขั้นตอนจาก Google Cloud Console:
1. เข้าสู่ระบบ console.cloud.google.com
2. ไปที่ APIs & Services > Credentials
3. กด + Create Credentials > เลือก OAuth client ID
4. Application type: เลือก Web application
5. คัดลอก Client ID มาวางในช่องด้านบน แล้วกดบันทึก
